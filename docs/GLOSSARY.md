# Glossary

One name per concept, in code and in prose, so an agent can grep. UI word ↔ code/DB word.

| Term                      | Meaning                                                                                                                                                                                                                                                                                                                        | In code / DB                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| LAP                       | Last Asylum Plague, the game. Its API keys start with `lap_`. Never "LAT".                                                                                                                                                                                                                                                     | `LAP_API_KEY`                                                        |
| the tracker               | lastasylumtracker.com, the third-party site and API we read                                                                                                                                                                                                                                                                    | —                                                                    |
| LAPTracker                | this project                                                                                                                                                                                                                                                                                                                   | —                                                                    |
| event                     | one game event: a scheduled event or a manual event (D28)                                                                                                                                                                                                                                                                      | `events`                                                             |
| scheduled event           | the weekly event on `EVENT_WEEKDAY` (Saturday by default), made by the tick a day ahead; default title `<Weekday> Event <date>`                                                                                                                                                                                                | `events.manual = false`                                              |
| manual event              | a public event the owner creates on /admin and runs by hand; no schedule, never run by the tick (D28)                                                                                                                                                                                                                          | `events.manual`                                                      |
| event title               | a manual event's name or a renamed event's; none while a scheduled event keeps its generated name, so pages show the date (D49)                                                                                                                                                                                                | `eventTitle`, `isGeneratedName`                                      |
| snapshot                  | one collection run for one event and phase                                                                                                                                                                                                                                                                                     | `snapshots`                                                          |
| daily read                | the tick's once-a-day read of the tracked set and the workspaces' alliances at the end of the server day, event days included; not an event, not a snapshot (D60, D72, D133); "daily update" is the UI word (PT "atualização diária", FR "mise à jour quotidienne"; never "read", "leitura" or "relevé" in UI copy, issue 585) | `daily_reads`, `daily_rosters`                                       |
| ranks board               | the site's server ranks board (internal API, no quota): every alliance's might and kills and its place, read and stored once a server day (D133)                                                                                                                                                                               | `alliance_board`, `alliances`, `fetchRanks`                          |
| tracked set               | the day's top 20 alliances by board might: read every day and by the next event's Before (D133); "Read every day" is the UI word                                                                                                                                                                                               | `tracked_sets`, `TRACKED_COUNT`                                      |
| lookup                    | "Get today's details": one read of an alliance outside the daily read, once per alliance per server day for the whole site, at most 30 a day (D133)                                                                                                                                                                            | `alliance_lookups`, `lookupAlliance`                                 |
| alliance statement        | the text an alliance writes in game (`declaration`, else `bulletin`), shown as written with its joining rules (D128)                                                                                                                                                                                                           | `allianceStatement`, `AllianceStatementCard`                         |
| member history            | an alliance's rosters over time, each compared with the previous usable one: joined, left, renamed, kills and might changes (D60)                                                                                                                                                                                              | `memberHistory`, `/alliances/[id]/history`                           |
| workspace                 | the private area of one alliance, for its leadership only: Discord sign-in, every roster field of its members, en/pt-BR/fr (D71)                                                                                                                                                                                               | `workspaces`, `lib/private`, `/w/[slug]`                             |
| calendar entry            | one plan in a workspace's calendar (issue 300): a game event or another event, once or every week                                                                                                                                                                                                                              | `calendar_entries`, `/w/[slug]/calendar`                             |
| occurrence                | one week of a calendar entry; its row keeps only what differs that week: a move, a cancel, the caravan's picks                                                                                                                                                                                                                 | `calendar_occurrences`, `Placed`                                     |
| roll call                 | one occasion an officer marks members for (issue 298): Raid prep (the kind `shield`; "KvK shield" before 2026-11-19, "Raid Shield" before 2026-11-20, D137), an Undead Siege, a Cheese Trap or an Elixir Scramble team; from a calendar entry's week or added by hand                                                          | `roll_calls`, `/w/[slug]/roll-call`                                  |
| mark                      | one member's answer in a roll call: ✓, ✗ or "no problem seen"; none is "not set", which never counts against anyone (D75). Raid prep has a second mark per member, squads off the wall (`part` `wall`, D137)                                                                                                                   | `roll_call_marks` (`yes`/`no`/`assumed`)                             |
| Raid Shield check         | the tracker's two reads of every member's shield the night before KvK: the **night check** (Friday from 23:30 ST; readings from 23:00–00:00 ST count) and the **morning check** (Saturday from 10:00–11:00 ST), never after 12:00 ST (D137); one name in every place, never "Friday's read" (issue 585)                        | `shield_check`, `shield_checks`, `player_reads.shielding`            |
| away dates                | a member's first and last day away (the `away` fact); on those days they are left out of roll calls and suggestions                                                                                                                                                                                                            | `away` `{ text, from?, until }`, `awayOn`                            |
| pending member            | a new member an officer added by hand before the roster lists them; matched to one roster member by name key, or linked by hand (D106)                                                                                                                                                                                         | `pending_members`, uid `-id`                                         |
| needs linking             | a pending member a roster read after their add still could not match to exactly one member; officers link them by hand (D106, 2026-11-17)                                                                                                                                                                                      | `toMatch`                                                            |
| removed                   | a pending member an officer removed from the list; the row, its facts and points are kept and adding the same name reopens it (D106, 2026-11-17)                                                                                                                                                                               | `pending_members.dismissed_at`                                       |
| former member             | a uid an earlier roster of the workspace's alliance listed and its newest roster does not; keeps its member facts (D107)                                                                                                                                                                                                       | `formerMembers`, `?view=former`                                      |
| self-report               | what a member sent about themselves from their own page (AD Tech, time zone, languages), kept apart from the officers' member facts; the card says "Member says" / "Self-reported" until an officer answers. Put on the card, it becomes a fact "from the member" (D154)                                                       | `member_self_reports`, `lib/private/self-report.ts`, source `member` |
| feedback                  | what an officer or a member sends the site's owner from the desk or the board with "Send feedback": an idea, a problem or something good, without their name; collect only, kept 180 days, read on /admin/feedback (D157)                                                                                                      | `feedback`, `lib/private/feedback.ts`, `/admin/feedback`             |
| ST                        | server time, the game's clock (`SERVER_TZ`, UTC−2); the calendar shows each time in ST and on the viewer's clock. "ST" in every language, after every desk, board and Me time ("18:54 ST"); spelled out only in a legend: "server time (ST)", PT "horário do servidor (ST)", FR "heure du serveur (ST)" (issue 585)            | `zonedInstant`, `clockIn`                                            |
| date words                | the desk's one way to write a date or a time, one form per purpose: "Fri, Nov 20" in a line, "Fri, Nov 20, 18:54 ST" with a time (PT "às", FR "à"), "November 20" where a sentence ends with it; a zone is its offset, "UTC−3" (issue 585)                                                                                     | `dateWords`, `lib/date-words.ts`, `offsetLabel`                      |
| members' board            | the read-only page of a workspace for its regular members (in the server with one of its member roles): the next 7 days' entries ("Next 7 days"; "This week" is always Monday to Sunday) and notices marked for members, and Start here (D105)                                                                                 | `/w/[slug]/board`, `start_here`                                      |
| notice                    | an officer-written text for the game or Discord, kept in the workspace's notices library in en/pt-BR/fr (D81)                                                                                                                                                                                                                  | `notices`, `/w/[slug]/notices`                                       |
| theft                     | a Secret Operations theft of quest rewards from a workspace member by another player, followed up per attacker (D97)                                                                                                                                                                                                           | `thefts`, `theft_follow_ups`                                         |
| follow-up                 | an officer's record about a member on the week's Follow-up list: talked, on a break, needs help or all fine, with a note (D104); for thefts, see theft                                                                                                                                                                         | `member_follow_ups`, `/w/[slug]/follow-up`                           |
| noted                     | a member with a follow-up still counting since Monday 00:00 ST: off the week's list, shown under "Noted this week" with who noted them, when and the note; never "done", which reads as closed (D104, issue 585)                                                                                                               | `notedThisWeek`, `NotedItem`, `WeekCounts.noted`, `notedSince`       |
| Needs help (mark)         | an officer's status that a member needs help (the `status` fact, D80): on Follow-up's first group "Needs help · n" every week until an officer taps "No longer needs help" or clears it in Edit info; a break pauses it; rows and the card say since when, who added it and why (D104, issue 585 slice 2)                      | `officerStatus === "help"`, `WorkItem.help`, `helpMark`              |
| worth a hello             | Follow-up's group of members with a reason to check in (quiet, might the same, KvK), titled "Worth a hello · n" (was "Check in · n"; issue 585)                                                                                                                                                                                | `followup.group.checkin`, `WorkItem.checkIn`                         |
| ready message             | a short message to a member, in their language (EN, PT or FR), that an officer copies into the game's mail or Discord; never sent by the app (D137, D140)                                                                                                                                                                      | `lib/private/ready-message.ts`                                       |
| coins tip                 | Follow-up's tip when Alliance Help coins were below 1,000 on at least 5 of the last 7 days with a read; days with no read never count (D140)                                                                                                                                                                                   | `coinsTip`                                                           |
| avatar frame              | the game's frame around a player's photo; the current one per player in `player_frames`, served by `/img/frame/[id]` (D65, D66)                                                                                                                                                                                                | `frameId`, `frame_id`                                                |
| phase                     | `before` or `after` the event                                                                                                                                                                                                                                                                                                  | `phase`                                                              |
| sample                    | a reading of every tracked alliance between an event's Before and After, one per slot; members as arrays; a stale sample has no change (D69)                                                                                                                                                                                   | `snapshots.phase = 'sample'`                                         |
| slot                      | an instant on the `SAMPLE_EVERY_MIN` grid from the hour (:00, :15, :30, :45); a sample is due from its slot until the next one (D69)                                                                                                                                                                                           | `snapshots.slot_at`, `slotOf`                                        |
| sampled event             | a public event with at least one usable sample (finished, a fresh alliance row with no error); the others are shown disabled in the sample-based views (D86)                                                                                                                                                                   | `sampledEventIds`                                                    |
| server fight clock        | `/events/fight-clock`: each event's slots on the server clock, as the share of the event's kills gained in each (D86)                                                                                                                                                                                                          | `getFightClock`, `eventClock`                                        |
| opponent                  | the server our server meets in a scheduled event's KvK, with up to 15 alliance tags the owner saves on /admin; its alliances are read once at the Start and once at the End (D152)                                                                                                                                             | `kvk_opponents`, `kvk_reads`, `collectOpponent`                      |
| matchup                   | the event page's "KvK matchup": our top n alliances against the opponent's, n the smaller count of usable Start readings (D152)                                                                                                                                                                                                | `matchupOf`, `eventMatchup`, `Matchup`                               |
| damage report             | the matchup's "Start to End" (the UI words): each side's might change and kills gained over its members in both readings, for the n chosen at the Start (D152)                                                                                                                                                                 | `Side.change`, `memberChange`                                        |
| might                     | total alliance power (UI word)                                                                                                                                                                                                                                                                                                 | `total_power` (API `power`)                                          |
| kills                     | sum of the roster's member kills                                                                                                                                                                                                                                                                                               | `total_kills`                                                        |
| board kills / board might | the server ranks board numbers; cross-check only, never in a delta                                                                                                                                                                                                                                                             | `kills_board`, `power_board`                                         |
| delta                     | after − before for one alliance, roster vs roster                                                                                                                                                                                                                                                                              | computed in `lib/compute.ts`                                         |
| fresh                     | roster `updated_at` within 20 min of the snapshot                                                                                                                                                                                                                                                                              | `is_fresh`                                                           |
| stale                     | not fresh; shown with a marker and no delta                                                                                                                                                                                                                                                                                    | `is_fresh = false`                                                   |
| complete                  | every row ok and fresh                                                                                                                                                                                                                                                                                                         | `status = 'complete'`                                                |
| partial                   | some rows missing or stale                                                                                                                                                                                                                                                                                                     | `status = 'partial'`                                                 |
| failed                    | no rows                                                                                                                                                                                                                                                                                                                        | `status = 'failed'`                                                  |
| source                    | where a row came from: the documented API or the internal fallback                                                                                                                                                                                                                                                             | `source` (`v1` \| `internal`)                                        |
| identity                  | an alliance's or player's permanent id; names and tags are labels with a history                                                                                                                                                                                                                                               | `union_id`, `uid`                                                    |
| tag                       | the alliance's short label (`abbr` in the API); case-sensitive, not unique                                                                                                                                                                                                                                                     | `tag`                                                                |
| name history              | distinct (tag, name) pairs per id, derived from snapshots                                                                                                                                                                                                                                                                      | `lib/queries/names.ts`                                               |
| quota                     | the 1,000 `/v1` requests per UTC day                                                                                                                                                                                                                                                                                           | `remaining`                                                          |
| tick                      | the 15-minute scheduler call that decides whether a snapshot is due                                                                                                                                                                                                                                                            | `POST /api/tick`                                                     |
| blocked roster keys       | roster fields kept in `raw_json`, never served outside `lib/private` (D71); D76 lets three of them out as aggregates, see there                                                                                                                                                                                                | `BLOCKED_ROSTER_KEYS`                                                |
| daily quest points        | roster key `active`: the quest points a member earned since the week's reset (Monday, 00:00 ST), a running total, not a day's value. A day's points are derived from two reads (`questPoints`); the week's are the newest read of the week. Cap about 240 a day, provisional (D127, amended 2026-11-22)                        | `active`, `questPoints`, `weekQuestPoints`                           |
| Alliance Help coins       | roster key `daily_honor`: a member's Alliance Help coins today, max 1,000 ("Daily Alliance Coin" on the Alliance Help screen); not honor (D127)                                                                                                                                                                                | `daily_honor`, `dailyHonor`                                          |
| tech donated              | roster key `daily_tech`: the tech a member donated today. The game sends null, never 0, for all three keys; on a read that lists the member, null is "none today" (D127)                                                                                                                                                       | `daily_tech`, `weekDonations`                                        |
| reference value           | an event's `after` row (fallback `before`), used for across-events deltas                                                                                                                                                                                                                                                      | `lib/compute.ts`                                                     |
| ledger rank               | an alliance's position among the tracked alliances by might or by kills, per snapshot or per event; a player's, among their alliance's roster                                                                                                                                                                                  | `compute.rankBy`, `lib/queries/ranks.ts`                             |
| server rank               | the game's own power ranking of the alliance on the server                                                                                                                                                                                                                                                                     | `server_rank` (API `rank.rank`)                                      |
| rank movement             | places moved between two ranks: `▲k` up, `▼k` down, `=` held, `—` unknown                                                                                                                                                                                                                                                      | `compute.rankDelta`                                                  |
| copy / blank dictionary   | every user-facing string, keyed; the blank dictionary replaces each value with `░` for the ten-second test                                                                                                                                                                                                                     | `lib/copy.ts`, `NEXT_PUBLIC_BLANK_COPY`                              |
| dictionary / language     | the public pages' strings in one language (`en`, `lib/copy.<tag>.ts`), picked per request from the `lang` cookie or Accept-Language (D48)                                                                                                                                                                                      | `requestCopy`, `useCopy`                                             |
