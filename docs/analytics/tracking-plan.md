# Tracking plan (D115)

What we send to PostHog (project 741657, US cloud, D77) and which product question each event answers. An event that answers no question here is not added.

## Rules for every event

- No member values, no names, no free text, no roster private fields (CLAUDE.md, D71, D76), no Discord id, no email.
- Properties are enums from a closed list, booleans, or counts. In the browser, `lib/analytics/events.ts` types every property as a closed list of words, and `events.test.ts` fails `pnpm check` if a property could take any string or a number. On the server, `lib/analytics/server.ts` is the closed list; `server.test.ts` checks the payloads.
- `before_send` (`lib/analytics/sanitise.ts`) adds `area` (`public`, `workspace`, `admin`), `workspace` (the slug) and `section` (the tab, below) from the event's own path, and cuts query strings and hashes from every URL.
- People first (D75): nothing here ranks officers or members. Events count use of the desk, not who did the most.

## Who is counted

| Where the page load starts             | Distinct id                                                                                                      | Person profile                                                 | Replay            |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ----------------- |
| A public page                          | PostHog's cookieless daily hash (IP, user agent, host, a daily salt that PostHog deletes)                        | none                                                           | none              |
| `/w/<slug>` (desk or board), signed in | `ws_` + 32 hex: HMAC of the workspace user id under a key derived from `CRON_SECRET` (`lib/analytics/person.ts`) | `tier` (`officer` or `member`) and `workspace` (the slug) only | yes, masked (D77) |
| `/admin`, or `/w` signed out           | a random id for this page load                                                                                   | none                                                           | yes, masked (D77) |

So: daily unique visitors on public pages are real (one hash per visitor per day); desk and board users are real across days and devices; nothing is stored on the device. Sign-out calls `reset`.

## Changed in D115

- "Paste updates" sent `ws_screenshot_sent` with `kind: member_update`, which counted a paste as a screenshot. It now sends `ws_updates_pasted`.
- Exception messages are scrubbed in every area instead of replaced by `[masked]` on the workspace and `/admin`.

## Not tracked, on purpose

- Who marked, saved, thanked or was thanked; any member's value; anything typed.
- Per-member actions on `/admin`.
- OpenTelemetry traces (D115: not now).
